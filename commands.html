K3V's Giveaway Bot Commands

OldToons.world • Oldtoons BON Giveaway

USER Commands
!help
Displays help info for all available commands.
!bon
Displays the current prize amount for the ongoing giveaway.
!range
Displays the valid number range for current giveaways.
!time
Displays the time left until the giveaway ends.
!number
Submit a number guess for number-based giveaways.
!taken
Shows the list of currently taken numbers.
!free
Shows currently available (free) numbers — if enabled.
!random
Generates a random number within range (if enabled).
!change #
Change your random number once (only for !random entries).
!lucky
Displays the current lucky number (if enabled).
!entries
Shows how many entries you or others have made.
!stats
Current giveaway statistics overview.
!leave
Leave the current giveaway.
!sponsors
Shows all current sponsors and their BON contributions.
!spots
Shows how many spots are still available.
!leaderboard
Top winners leaderboard.
!mystats
Your personal entries/wins/losses statistics.
!myrank
Show your current position on the leaderboard.
!history
Show recent giveaway results.
!lastwinner
Information about the last giveaway winner(s).
!banlist
Show list of currently banned users.
HOST Commands
!addbon #
Add BON to the prize pool.
!removebon #
Remove BON from the prize pool.
!addtime #
Add time to the giveaway (in minutes).
!removetime #
Remove time from the giveaway.
!reminder
Displays current giveaway information.
!summon (@user)
Summon user to ChatBox (Send PM)
!kick (@user)
Kick a user from the current giveaway.
!ban (@user)
Permanently ban user from giveaways.
!unban (@user)
Remove ban from a user.
rig (@user)
(For testing) Simulates a rigged outcome (host/debug use).
unrig
(For testing) Restores fairness after a rigged outcome.
!winners #
Change number of winners for the giveaway.
!exportstats
Export the entire leaderboard & stats.
!resetstats
Reset the entire leaderboard & stats.
!pause
Pause the giveaway timer.
!resume
Resume a paused giveaway.
!end
Force end the giveaway.
